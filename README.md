# Tide & Trove — Made for the Dar Al Fikr AI Competition
Tide and Trove is a simulator museum management game that aims to teach people about fossils. It is completely Vibe-coded with Claude Code and made in Godot 4.7.2 and GDScript. The game was made for the Dar Al Fikr AI competition for 2026.
# Q&A
**Q: What is this game about?**
**A: Tide & Trove is a museum management game that aims to teach people about history and fossils, you dig up fossils and display them in your museum called "Ammonite Bay" and get visitors. Get money for upgrades and better equipment, or just collect fossils and read about them, the choice is yours!**
**Q: What AI do you use and how much does it cost?**
**A: We use Claude Code for all the coding and modeling. You need a Claude subscription and the one we have (which is the cheapest) is 20$ without tax.**
